# 绝望岛求生记 · 微信小游戏（Canvas 原生版）

鲁滨逊漂流记主题 · 合成放置 · IAA 变现
网页 Demo 的完整移植，机制与动效逐项保留。

> 「绝望岛」（Island of Despair）是原著中鲁滨逊登陆后给荒岛起的名字。
> 原著公版细节（木刻记日、两季、巨杉独木舟、沙滩脚印、鹦鹉 Poll 等）作为内容层与彩蛋层叠加，详见 `js/data.js` 的「V1.12 鲁滨逊改编层」。
>
> V1.13 继续深挖原著里**容易被读者漏掉**的细节，做成一次性彩蛋事件与常驻状态：
> 树上的第一夜（通宵下雨却酣睡）／口袋里的谷壳（种植是意外开始的）／老山羊（拖出去挖坑埋了）／
> 海上的火光（船回了两炮，他始终不知道有没有人获救）／猫太多了（繁殖太快，只留两三只）／
> 两枚金币与一只烟斗（他看重烟斗远胜过金币）／它老了（狗活到 19 岁，其中 16 年陪着他）／
> 还有「墨水会用完」（他想不出任何办法制造墨水）与自嘲口吻的「既是个蹩脚的木工，也是个蹩脚的裁缝」。
> 所有新增内容只取公版原著细节，未使用任何在保护期内的 IP 素材。

## 目录结构

```
荒岛求生记-wechat/
├── game.js              # 入口（加载各模块并启动）
├── game.json            # 小游戏配置（竖屏）
├── project.config.json  # 微信开发者工具项目配置
└── js/
    ├── data.js          # 数据层：资源表/建造表/文案库/日记/颜色
    ├── fx.js            # 动效层：飘字/粒子/toast/天数过渡/营地升级光晕
    ├── render.js        # 渲染层：首页/CG/棋盘/建造/日记/弹窗 + 触摸命中
    ├── ad.js            # 广告管理器：激励视频 + Banner（演示/正式双模式）
    └── app.js           # 主逻辑：合成/采集/建造/漂流瓶/离线收益/主循环
```

## 如何运行

1. 打开**微信开发者工具**
2. 选择「小游戏」→「导入项目」
3. 目录选择 `荒岛求生记-wechat/` 这一层（含 game.js 的目录）
4. AppID 选「测试号」（游客模式）或填你的小游戏 AppID
5. 点击编译即可运行

## 已保留的机制（与网页版一致）

- 合成棋盘（5 列，3 合 1 自动升级，连锁合成）
- 采集 + 体力（10 点，30s 回 1，看广告 +5）
- 空手文案库（20 条鲁滨逊风，25% 概率 demo 用）
- 营地建造 4 阶段（避难棚/储物窖/栅栏围墙/信号烽火）
- 离线收益（避难棚解锁，按分钟产出）
- 漂流瓶（免费 1 次 + 看广告加捞）
- 日记解锁（7 篇，建造+天数驱动）
- 轮回重生（结局后新周目，体力上限 +建成数）
- 资源计数（木材/食物/石料棋盘内实时统计）
- 存档（wx.setStorageSync，含版本兼容与离线体力补算）

## 广告接入（开通流量主后）

1. 微信公众平台开通流量主，创建**激励视频**与 **Banner** 广告位
2. 打开 `js/ad.js`，填入广告位 ID：
   ```js
   var REWARD_UNIT = 'adunit-xxxxxxxxxxxxxxxx';  // 激励视频
   var BANNER_UNIT = 'adunit-yyyyyyyyyyyyyyyy';  // Banner（可选）
   ```
3. 留空 = 演示模式（模拟确认框，与网页版一致）

## 上线前待调项

- `js/data.js` 的 `E_INTERVAL`：30000（30s）→ 180000+（3-5 分钟）
- `js/data.js` 的 `MISS_RATE`：0.25 → 0.08-0.12
- 体力上限、建造数值需以真实留存数据校准
- 美术素材：先用 emoji 占位，后续按 AI 管线产出 PNG 替换
- Banner 在非游戏主场景可隐藏（`AD.hideBanner()`）
